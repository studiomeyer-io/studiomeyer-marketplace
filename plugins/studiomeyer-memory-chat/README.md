# StudioMeyer Memory for Claude

This plugin connects Claude to a user's own StudioMeyer Memory account. It offers a small set of actions: recall saved memories, find named concepts, inspect one concept's observations and relationships, and save a specific fact or insight at the user's request. A matching skill explains when to use those actions and how to report their results. The user signs in through StudioMeyer Memory; the plugin contains no credentials. It does not collect Claude chat history or run automatic prompt hooks. The hosted service may require an account, and service plan limits apply.

Connect the `studiomeyer-memory` connector from this plugin's Connectors tab and sign in. Then ask, for example, “What did I save about the launch plan?” or “Remember that our kickoff is on Friday.”
